## 2. 核心业务链路

### 2.1 链路A：报价→合同→交付（主线）

```
线索/商机 → 报价单 → 审批 → 发送客户 → 客户确认 → 合同 → 交付
```

### 2.2 链路B：招标文件→标书→中标（投标链路）

```
招标文件 → OCR解析 → 提取要求 → 生成标书 → 审核 → 提交 → 中标跟踪
```

## 4. 入口与链路总规则

### 4.1 入口独立性铁律（强制规范）

- 每个一级入口可独立进入
- 不强制"必须从报价开始"
- 支持从合同中心直接上传合同
- 支持从标书中心直接开始投标

### 4.2 三个一级入口

| 入口 | 定位 | 独立开局能力 |
|------|------|------------|
| 报价中心 | 独立完成报价流程 | 是 |
| 合同审核 | 独立上传合同审核 | 是 |
| 标书中心 | 独立解析招标文件 | 是 |

### 4.3 对象关联规则

- 报价单 → 可选关联合同
- 合同 → 可选关联报价单
- 标书 → 可选关联报价/合同

## 5. 核心对象状态机

### 5.1 报价单状态机

```
DRAFT → PENDING_APPROVAL → APPROVED → SENT → CONFIRMED
            ↓
        REJECTED
```

**状态说明**：
- 草稿：创建后未提交的报价
- 待审批：包含超额折扣或特殊条款
- 已批准：审批通过但未发送
- 已发送：已发送给客户
- 已确认：客户确认接受
- 已拒绝：客户拒绝

### 5.2 合同审核状态机

```
PENDING → PARSING → ANALYZING → COMPLETED
                              → FAILED
```

### 5.3 审批单状态

```
PENDING → APPROVED
        → REJECTED
        → TRANSFERRED
        → TIMEOUT
```
