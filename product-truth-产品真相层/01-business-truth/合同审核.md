### 2.2 核心设计原则

- **本地优先**：合同文本敏感，默认本地模型处理，不上传云端
- **工具解耦**：通过OpenAI兼容API对接任意本地模型工具（LM Studio等），不绑定特定工具
- **双轨规则**：结构化YAML规则（100%精确）+ 自然语言语义规则（灵活理解）
- **智能路由**：根据合同页数、复杂度自动选择本地/云端模型
- **双轨输出**：Word批注（给法务）+ 审核报告（给客户/销售）

### 3.2 批注生成核心实现

```python
from docx import Document
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def add_comment(paragraph, text, author="AI审核", start=0, end=None):
    """在段落指定位置添加批注"""
    if end is None:
        end = len(paragraph.text)

    # 创建批注ID
    comment_id = get_next_comment_id()

    # 创建批注内容
    comment = OxmlElement('w:comment')
    comment.set(qn('w:id'), str(comment_id))
    comment.set(qn('w:author'), author)
    comment.set(qn('w:date'), datetime.now().isoformat())

    # 批注文本段落
    comment_para = OxmlElement('w:p')
    comment_run = OxmlElement('w:r')
    comment_text = OxmlElement('w:t')
    comment_text.text = text
    comment_run.append(comment_text)
    comment_para.append(comment_run)
    comment.append(comment_para)

    # 标记原文位置
    run = paragraph.runs[0] if paragraph.runs else paragraph._p
    comment_range_start = OxmlElement('w:commentRangeStart')
    comment_range_start.set(qn('w:id'), str(comment_id))
    run.insert(0, comment_range_start)

    comment_range_end = OxmlElement('w:commentRangeEnd')
    comment_range_end.set(qn('w:id'), str(comment_id))
    run.append(comment_range_end)

    return comment_id
```

### 3.3 位置定位算法

```python
def find_text_position(doc, target_text, context=""):
    """
    在文档中定位目标文本的位置

    Args:
        doc: Document对象
        target_text: 要查找的文本
        context: 上下文文本（用于精确定位）

    Returns:
        (paragraph_index, start_char, end_char) 或 None
    """
    for para_idx, paragraph in enumerate(doc.paragraphs):
        text = paragraph.text
        if target_text in text:
            start = text.index(target_text)
            end = start + len(target_text)
            return (para_idx, start, end)

        # 如果直接找不到，尝试模糊匹配
        if context and context in text:
            # 在上下文附近查找
            start = text.index(context)
            return (para_idx, start, start + len(context))

    return None
```

### 3.4 双方案设计

**方案A：Word批注（推荐）**

```
输入：合同Word文档 + 审核结果JSON
输出：带批注的Word文档

优点：
- 法务可直接在Word中查看和回复
- 支持按批注导航
- 保留原文档格式

缺点：
- 需要Word软件打开
- 批注格式受限
```

**方案B：审核报告兜底**

```
输入：审核结果JSON
输出：HTML/网页审核报告

优点：
- 无需Word，浏览器即可查看
- 支持交互式操作（筛选、排序）
- 可嵌入系统UI

缺点：
- 法务无法直接编辑
- 需要额外开发UI
```

**最终策略**：
- 默认输出Word批注（给法务）
- 同时生成审核报告（给客户/销售）
- 支持导出为PDF（归档用）

### 4.2 规则引擎执行

```typescript
interface RuleResult {
  ruleId: string;
  triggered: boolean;
  extractedValue?: string;
  threshold?: string;
  comparison?: string;
  matchedCondition?: string;
  message: {
    title: string;
    description: string;
    suggestion: string;
  };
  executionTime: number;
}

// 规则执行
async function executeRule(
  rule: RuleConfig,
  contractText: string
): Promise<RuleResult> {
  const startTime = Date.now();

  // 1. 提取字段值
  const extractedValue = await extractField(
    rule.condition.field,
    contractText
  );

  // 2. 比较判断
  const triggered = compare(
    extractedValue,
    rule.condition.operator,
    rule.condition.value
  );

  // 3. 生成结果
  return {
    ruleId: rule.id,
    triggered,
    extractedValue: String(extractedValue),
    threshold: String(rule.condition.value),
    comparison: `${extractedValue} ${rule.condition.operator} ${rule.condition.value}`,
    matchedCondition: triggered ? rule.condition.operator : undefined,
    message: rule.message,
    executionTime: Date.now() - startTime,
  };
}
```

### 5.3 OCR 解析与结构化

```python
from paddleocr import PaddleOCR
import json

class ContractOCR:
    def __init__(self):
        self.ocr = PaddleOCR(use_angle_cls=True, lang='ch')

    def parse_contract(self, image_path):
        """解析合同图片，返回结构化结果"""
        result = self.ocr.ocr(image_path, cls=True)

        # 提取文本
        text_blocks = []
        for line in result[0]:
            if line:
                text_blocks.append({
                    'text': line[1][0],
                    'confidence': line[1][1],
                    'bbox': line[0]
                })

        # 结构化处理
        structured = self._structure_text(text_blocks)

        return {
            'raw_text': '\n'.join([b['text'] for b in text_blocks]),
            'structured': structured,
            'metadata': {
                'total_pages': 1,
                'total_blocks': len(text_blocks),
                'avg_confidence': sum(b['confidence'] for b in text_blocks) / len(text_blocks)
            }
        }

    def _structure_text(self, text_blocks):
        """将OCR结果结构化"""
        structured = {
            'parties': [],
            'key_terms': [],
            'payment_terms': [],
            'liability_clauses': [],
            'termination_clauses': []
        }

        # 识别甲乙双方
        for block in text_blocks:
            text = block['text']
            if '甲方' in text or '乙方' in text:
                structured['parties'].append(text)
            elif '付款' in text or '账期' in text:
                structured['payment_terms'].append(text)
            elif '违约' in text or '赔偿' in text:
                structured['liability_clauses'].append(text)

        return structured
```
