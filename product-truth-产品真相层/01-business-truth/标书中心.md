## 2. 标书中心产品电路

```
输入层
├── 招标文件（PDF/Word）
│   ├── 招标公告
│   ├── 投标人须知
│   ├── 评标办法
│   ├── 合同条款
│   └── 技术规格书
│
└── 企业资质文件
    ├── 营业执照
    ├── 资质证书
    ├── 业绩证明
    └── 人员简历

处理层
├── OCR解析（PaddleOCR）
│   ├── 文本提取
│   ├── 表格识别
│   └── 结构化处理
│
├── 关键信息提取
│   ├── 评分标准
│   ├── 技术参数
│   ├── 商务条款
│   └── 时间节点
│
└── 标书生成
    ├── 模板匹配
    ├── 内容填充
    ├── 格式排版
    └── 自动编号

输出层
├── 结构化招标要求
├── 评分标准对比表
├── 技术偏离表
└── 完整标书（Word/PDF）
```

## 3. 招标文件解析流程

```
用户上传招标文件
    │
    ▼
文件格式校验（PDF/Word）
    │
    ▼
OCR文本提取（PaddleOCR）
    │
    ▼
结构化解析
    │
    ├── 招标公告 → 项目基本信息
    ├── 投标人须知 → 资格要求
    ├── 评标办法 → 评分标准
    ├── 合同条款 → 商务要求
    └── 技术规格书 → 技术要求
    │
    ▼
关键信息提取
    │
    ├── 评分项（权重）
    ├── 技术参数（偏离分析）
    ├── 商务条款（偏离分析）
    └── 时间节点（提醒）
    │
    ▼
生成结构化结果
```

## 4. 招标文件数据模型

```prisma
// 招标项目
model Tender {
  id          String   @id @default(cuid())
  tenderNo    String   @unique     // 招标编号
  title       String               // 项目名称
  orgName     String               // 招标单位
  budget      Decimal?             // 预算金额
  deadline    DateTime             // 投标截止日
  status      TenderStatus @default(PENDING)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  requirements TenderRequirement[]
  scores      TenderScore[]
}

// 招标要求
model TenderRequirement {
  id        String   @id @default(cuid())
  tenderId  String
  tender    Tender   @relation(fields: [tenderId], references: [id])
  category  String                 // 类别：技术/商务/资质
  content   String                 // 要求内容
  weight    Float?                 // 权重
  isMust    Boolean @default(false) // 是否必须满足
}

// 评分标准
model TenderScore {
  id        String   @id @default(cuid())
  tenderId  String
  tender    Tender   @relation(fields: [tenderId], references: [id])
  item      String                 // 评分项
  weight    Float                  // 权重
  maxScore  Float                  // 最高分
}

enum TenderStatus {
  PENDING    // 待解析
  PARSING    // 解析中
  PARSED     // 已解析
  GENERATING // 生成标书中
  COMPLETED  // 已完成
}
```

## 6. 标书生成流程

```
    ▼

    │

自动填充企业信息
    │

    ├── 资质证书
    ├── 业绩证明
    └── 人员简历
    │
    ▼
技术方案编写（AI辅助）
    │
    ├── 技术参数响应
    ├── 技术偏离分析
    └── 项目实施方案
    │
    ▼
报价部分生成
    │
    ├── 从报价中心取报价
    ├── 生成报价表
    └── 报价说明
    │
    ▼
生成完整标书
    │
    ├── Word格式

    └── 在线预览
```
