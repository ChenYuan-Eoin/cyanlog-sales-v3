## 1. 日程中心产品电路

```
输入层
├── 报价单状态变更
│   ├── 报价已发送 → 创建跟进提醒（3天后）
│   ├── 报价已确认 → 创建合同生成提醒
│   └── 报价已拒绝 → 创建复盘提醒
│
├── 合同审核状态
│   ├── 审核完成 → 创建法务审阅提醒
│   └── 审核失败 → 创建重新提交提醒
│
├── 手动创建
│   ├── 客户拜访
│   ├── 内部会议
│   └── 项目里程碑
│
└── 外部同步
    ├── 飞书日历
    └── 企业微信日历（预留）

处理层
├── 提醒规则引擎
│   ├── 规则匹配
│   ├── 时间计算
│   └── 优先级排序
│
├── 提醒通道
│   ├── 应用内通知
│   ├── 飞书消息
│   ├── 邮件
│   └── 短信（预留）
│
└── 日历同步
    ├── 添加到个人日历
    ├── 添加到团队日历
    └── 共享日历（预留）

输出层
├── 提醒通知
├── 日历视图
└── 日程报表
```

## 2. 日程类型

| 类型 | 触发条件 | 默认提醒时间 | 提醒方式 |
|------|---------|------------|---------|
| 报价跟进 | 报价发送后 | 3天后 | 应用内+飞书 |
| 报价到期 | 报价有效期前 | 到期前3天 | 应用内+飞书 |
| 合同审核 | 合同上传后 | 审核完成后 | 应用内 |
| 客户拜访 | 手动创建 | 开始前1小时 | 应用内+飞书 |
| 内部会议 | 手动创建 | 开始前15分钟 | 应用内 |
| 项目里程碑 | 项目计划 | 到期前1天 | 应用内+飞书 |
| 审批超时 | 审批超时前 | 超时前2小时 | 应用内+飞书+邮件 |
| 资质到期 | 资质到期前 | 到期前30天 | 应用内+飞书+邮件 |

## 3. 关键节点提醒规则

### 3.1 报价相关

```yaml
reminders:
  quote_sent:
    trigger: "quote.status = SENT"
    delay: "3 days"
    message: "报价已发送3天，请跟进客户反馈"
    channel: [app, feishu]

  quote_expiring:
    trigger: "quote.valid_until <= 3 days"
    delay: "0"
    message: "报价即将到期，请确认是否延期"
    channel: [app, feishu]

  quote_confirmed:
    trigger: "quote.status = CONFIRMED"
    delay: "0"
    message: "报价已确认，请生成合同草稿"
    channel: [app, feishu]
```

### 3.2 审批相关

```yaml
reminders:
  approval_timeout:
    trigger: "approval.created_at + timeout - 2 hours"
    delay: "0"
    message: "审批即将超时，请尽快处理"
    channel: [app, feishu, email]

  approval_escalation:
    trigger: "approval.status = TIMEOUT"
    delay: "0"
    message: "审批已超时，已升级至上级"
    channel: [app, feishu, email]
```

## 4. 日程数据模型

```prisma
// 日程
model Schedule {
  id          String   @id @default(cuid())
  title       String
  description String?
  type        ScheduleType
  status      ScheduleStatus @default(PENDING)
  startTime   DateTime
  endTime     DateTime?
  allDay      Boolean @default(false)
  remindAt    DateTime?
  remindChannel String[] // ["app", "feishu", "email"]
  relatedId   String?    // 关联业务ID
  relatedType String?    // 关联业务类型
  userId      String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

enum ScheduleType {
  QUOTE_FOLLOW    // 报价跟进
  QUOTE_EXPIRE    // 报价到期
  CONTRACT_REVIEW // 合同审核
  CUSTOMER_VISIT  // 客户拜访
  INTERNAL_MEETING // 内部会议
  MILESTONE       // 项目里程碑
  APPROVAL        // 审批提醒
  CERT_EXPIRE     // 资质到期
}

enum ScheduleStatus {
  PENDING    // 待处理
  COMPLETED  // 已完成
  CANCELLED  // 已取消
  OVERDUE    // 已过期
}
```

## 5. 提醒触发机制

### 5.1 触发方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 状态触发 | 业务状态变更时触发 | 报价发送、合同审核完成 |
| 时间触发 | 到达指定时间触发 | 会议提醒、到期提醒 |
| 周期触发 | 按周期重复触发 | 日报、周报 |
| 手动触发 | 用户手动创建 | 客户拜访、内部会议 |

### 5.2 提醒通道

| 通道 | 优先级 | 延迟 |
|------|--------|------|
| 应用内通知 | P0 | 实时 |
| 飞书消息 | P0 | 实时 |
| 邮件 | P1 | 5分钟 |
| 短信 | P2 | 10分钟 |

## 6. 日历视图设计

### 6.1 视图类型

| 视图 | 说明 | 适用场景 |
|------|------|----------|
| 日视图 | 一天的时间线 | 查看当天详细安排 |
| 周视图 | 一周的时间表 | 查看本周概览 |
| 月视图 | 一个月的日历 | 查看月度规划 |
| 列表视图 | 按时间顺序列表 | 查看所有日程 |
