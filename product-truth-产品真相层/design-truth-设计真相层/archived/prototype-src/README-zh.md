# Cyanlog 页面包预览说明

## 预览入口

- 总入口：`index.html`
- 登录页：`login.html`
- 首页：`home-dashboard.html`
- 报价中心：`quote-center.html`
- 标书日程：`tender-schedule.html`
- 审批中心：`approval-center.html`
- 品牌中心：`brand-center.html`

## 预览方式

这是一个静态 HTML 页面包，不需要启动服务。

直接在浏览器打开以下文件即可：

- `index.html`：从登录页进入整套流程
- 也可以单独打开任意业务页面进行评审

## 交付方式

推荐直接交付整个文件夹，或交付压缩包：

- 文件夹名：`cyanlog-sales-platform-v3`
- 压缩包名：`cyanlog-sales-platform-v3-delivery.zip`

## 说明

- 所有页面依赖都在当前目录下的 `assets/` 内
- 不要只单独发送某一个 `.html` 文件，否则相对资源会丢失
