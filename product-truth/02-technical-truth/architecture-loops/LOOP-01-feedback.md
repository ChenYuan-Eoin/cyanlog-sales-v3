# 循环架构图 #1：用户反馈循环

> **参考来源**: ONES "需求-任务-发布-复盘" 循环、Supabase Realtime Feedback

## 节点流向图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           用户反馈循环 (Feedback Loop)                        │
│                           参考: ONES 需求-复盘循环                            │
└─────────────────────────────────────────────────────────────────────────────┘

     ┌───────────────┐
     │   用户交互    │  ← 用户在前端进行操作、遇到错误或产生反馈
     └───────┬───────┘
             │
             ▼
     ┌───────────────┐
     │  反馈收集层   │  ← 埋点、反馈表单、错误上报
     │               │    代码: components/feedback/
     │  • 页面埋点   │
     │  • 反馈按钮   │
     │  • 错误捕获   │
     └───────┬───────┘
             │
             ▼
     ┌───────────────┐
     │  数据传输层   │  ← 实时/准实时传输到后端
     │               │    代码: app/api/feedback/route.ts
     │  • HTTP API   │
     │  • WebSocket  │       参考: Supabase Realtime
     │  • Batch 队列 │
     └───────┬───────┘
             │
             ▼
     ┌───────────────┐
     │   存储与分析  │  ← 数据持久化与聚合分析
     │               │    代码: supabase/feedback_logs + SQL views
     │  • 原始日志   │
     │  • 聚合报表   │
     │  • 告警规则   │
     └───────┬───────┘
             │
             ▼
     ┌───────────────┐
     │  产品决策层   │  ← 转化为产品改进
     │               │    文档: product-truth/feature-packets/
     │  • 需求识别   │
     │  • 优先级排序 │
     │  • REQ 创建   │
     └───────┬───────┘
             │
             └────────────────────────────────────┐
                                                  │
                     ┌────────────────────────────┘
                     │
                     ▼
             ┌───────────────┐
             │   功能发布    │  ← 新功能上线
             │               │    代码: product-code/
             └───────┬───────┘
                     │
                     ▼
             ┌───────────────┐
             │   效果监测    │  ← 验证改进效果

                          ╚══════════════════════════════╝
```

## 实际代码路径

| 组件 | 路径 | 状态 |
|------|------|------|
| 反馈 API | `product-truth/product-code/app/api/feedback/route.ts` | 🟡 规划中 |
| 错误边界 | `product-truth/product-code/app/error.tsx` | ✅ 已存在 |

| 聚合视图 | `supabase/migrations/` | 🟡 规划中 |

## 失败时可观测输出

| 故障点 | 现象 | 输出位置 |
|--------|------|----------|
| 反馈 API 故障 | 用户提交反馈无响应 | 浏览器 console.error |
| 存储故障 | 反馈数据丢失 | 后端 error.log |
| 分析延迟 | 报表数据陈旧超过 24h | monitoring dashboard |

## 人工介入触发条件

| 触发条件 | 响应时间 | 介入角色 |
|----------|----------|----------|
| 反馈提交成功率 < 95% | 15 分钟 | 运维 |
| 同类错误反馈 > 10 条/小时 | 2 小时 | 产品经理 |
| 功能发布后满意度下降 | 24 小时 | 产品负责人 |
