## 实际代码路径

| 组件 | 路径 | 状态 |
|------|------|------|
| CI 配置 | `.github/workflows/ci.yml` | ✅ 已存在 |
| Vercel 配置 | `product-truth/product-code/vercel.json` | 🟡 可选 |
| 部署脚本 | `product-truth/product-code/package.json` | ✅ 已存在 |
| 健康检查 | `product-truth/product-code/app/api/health/route.ts` | 🔴 待创建 |

## 失败时可观测输出

| 故障点 | 现象 | 输出位置 |
|--------|------|----------|
| CI 失败 | PR 显示红叉 | GitHub Actions logs |
| 部署失败 | Vercel 构建错误 | Vercel Dashboard |
| 健康检查失败 | 部署标记失败 | /api/health 响应 |
| 生产故障 | 监控告警 | PagerDuty / Slack |

## 人工介入触发条件

| 触发条件 | 响应时间 | 介入角色 |
|----------|----------|----------|
| CI 失败阻断合并 | 即时 | 开发者 |
| 部署失败 | 15 分钟 | 运维 |
| 生产故障 | 5 分钟 | 全团队 |
| 健康检查失败 | 10 分钟 | 开发 |

## 与 12-Factor App 的映射

| 12-Factor 原则 | 本项目中实现 |
|----------------|--------------|
| **Build, release, run** | CI 构建 → Vercel 部署 → Production 运行 |
| **Processes** | Serverless Functions (stateless) |
| **Logs** | Vercel Logs + 可选外部聚合 |
| **Admin processes** | 管理后台 + 边缘函数 |
