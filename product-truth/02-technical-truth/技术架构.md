## 2. API 网关路由电路

### 2.1 路由规则

```
/api/auth/*      → Account 服务
/api/quotes/*    → 报价中心服务
/api/contracts/* → 合同审核服务
/api/configs/*   → 配置中心服务
/api/tenders/*  → 标书中心服务
/api/admin/*     → 管理后台服务
```

### 2.2 网关功能

| 功能 | 说明 | 实现 |
|------|------|------|
| 路由分发 | 按路径路由到不同服务 | Next.js API Routes |
| 认证鉴权 | Token验证、权限检查 | Middleware |
| 限流熔断 | 防止服务过载 | Redis + Rate Limit |
| 日志记录 | 请求/响应日志 | Winston |
| 错误处理 | 统一错误响应格式 | Error Handler |

## 3. 事件总线电路（EventBus）

### 3.1 事件类型

| 事件 | 触发条件 | 消费者 |
|------|---------|--------|
| QuoteCreated | 报价单创建 | 日程管理、通知服务 |
| QuoteSent | 报价单发送 | 日程管理、CRM同步 |
| QuoteConfirmed | 报价确认 | 合同生成、赢单统计 |
| ContractUploaded | 合同上传 | OCR解析、审核任务 |
| ContractReviewed | 审核完成 | 通知服务、报告生成 |
| ApprovalRequested | 审批请求 | 通知服务、日程管理 |
| ApprovalCompleted | 审批完成 | 报价状态更新、通知服务 |

### 3.2 事件总线架构

```
生产者 ────► Redis Stream ────► 消费者
    │                            │
    ├── Event: QuoteCreated      ├── 消费者A: 日程管理
    ├── Event: QuoteSent         ├── 消费者B: 通知服务
    ├── Event: ContractUploaded   ├── 消费者C: OCR解析
    └── Event: ApprovalRequested └── 消费者D: 审核任务
```

## 4. AI 服务降级策略

### 4.1 降级策略

```
第1级：本地模型（LM Studio）
  超时(>45s) → 第2级
  OOM/崩溃 → 第2级

第2级：云端模型（备用）
  云端也失败 → 第3级

第3级：规则引擎兜底（仅结构化规则）
  返回：结构化规则结果 + "AI分析不可用"提示
  状态：COMPLETED（有规则结果）或 FAILED（规则也失败）
```

### 4.2 路由阈值

```
LM Studio本地模型处理：
  - 页数 ≤ 15: 整体送入LM Studio本地模型
  - 15 < 页数 ≤ 40: 分段送入LM Studio本地模型
  - 页数 > 40: 整体送入云端模型

强制云端：
  - LM Studio本地模型健康检查失败
  - 用户手动选择
```

### 4.3 超时阈值

```
LM Studio本地模型调用超时: 45秒
语义规则单条超时: 45秒
文档解析超时: 30秒

超时后动作：
  自动降级到云端模型
  如果云端也失败 → 状态 FAILED
```

## 5. 服务间调用模式

### 5.1 同步调用

```typescript
// 同步调用（适用于需要立即响应的场景）
async function getQuoteDetails(quoteId: string) {
  const response = await fetch(`/api/quotes/${quoteId}`);
  return response.json();
}
```

### 5.2 异步调用

```typescript
// 异步调用（适用于耗时操作）
async function analyzeContract(contractId: string) {
  // 提交分析任务
  const task = await fetch('/api/contracts/analyze', {
    method: 'POST',
    body: JSON.stringify({ contractId }),
  });

  // 返回任务ID，前端轮询
  return task.json(); // { taskId: 'xxx', status: 'PENDING' }
}
```

### 5.3 事件驱动

```typescript
// 事件驱动（适用于解耦场景）
// 生产者
async function publishQuoteCreated(quote: Quote) {
  await eventBus.publish('QuoteCreated', {
    quoteId: quote.id,
    customerId: quote.customerId,
    amount: quote.totalAmount,
  });
}

// 消费者
async function handleQuoteCreated(event: Event) {
  // 创建跟进提醒
  await createFollowUpReminder(event.quoteId);
  // 通知CRM
  await syncToCRM(event);
}
```

## 6. 缓存策略电路

### 6.1 缓存层级

| 层级 | 技术 | 用途 | 过期时间 |
|------|------|------|----------|
| L1 浏览器缓存 | Cache-Control | 静态资源 | 1年 |
| L2 CDN缓存 | Vercel Edge | 页面缓存 | 60秒 |
| L3 应用缓存 | Redis | API响应 | 5分钟 |
| L4 数据库缓存 | PostgreSQL | 查询结果 | 30分钟 |

### 6.2 缓存策略

```
缓存策略：

1. 静态资源（CSS/JS/图片）
   ├── 长期缓存（Cache-Control: max-age=31536000）
   └── 文件名包含hash

2. API响应
   ├── GET请求 → 可缓存
   ├── POST/PUT/DELETE → 清除缓存
   └── 缓存键：URL + 用户ID + 查询参数

3. 数据库查询
   ├── 热点数据 → 内存缓存
   ├── 配置数据 → 本地缓存
   └── 会话数据 → Redis缓存
```

## 9. MVP 架构约束

### 9.1 架构原则

1. **单体优先**：MVP阶段使用Next.js单体架构，不拆分微服务
2. **本地优先**：AI模型默认使用本地LM Studio，云端作为备用
3. **最小依赖**：核心功能不依赖外部系统（CRM等），支持独立运行
4. **渐进式扩展**：架构预留扩展点，支持后续演进

### 9.2 性能约束

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 页面加载 | < 3s | 首屏加载时间 |
| API响应 | < 200ms | 简单查询 |
| 文件上传 | < 10s | 10MB以内 |
| AI分析 | < 45s | 本地模型 |
| 并发用户 | 50 | 同时在线 |

### 9.3 安全约束

| 约束 | 说明 |
|------|------|
| HTTPS | 所有通信必须加密 |
| Token认证 | API请求必须携带有效Token |
| 输入校验 | 所有输入必须校验 |
| SQL注入防护 | 使用ORM，禁止拼接SQL |
| XSS防护 | 输出编码，防止XSS |
| CSRF防护 | 使用SameSite Cookie |
| 敏感数据加密 | 密码bcrypt，Token随机生成 |
