# 检查清单治理机制
# CHECKLIST-GOVERNANCE

## 原则
> 无验收条件，不进入开发  
> 无自检报告，不提交验收  
> 无验收通过，不合并代码

---

## 流程

```
需求提出
   ↓
设计阶段（输出：设计文档 + 验收条件）
   ← PRD必须包含验收条件
   ← 验收条件必须可测试
   ↓
执行阶段（输出：代码 + 自检报告）
   ← 代码中必须有自检注释
   ← 提交信息关联验收单
   ↓
验收阶段（输出：验收报告）
   ← 通过/有条件通过/驳回
   ↓
合并/部署
```

## 验收单模板

```markdown
## [任务ID] 任务名称

### 1. 需求描述
[一句话说明做什么]

### 2. 设计输出
- 技术方案：[链接]
- 接口定义：[链接]
- 数据模型：[链接]

### 3. 验收条件
| 条件ID | 验收项 | 标准 | 测试方法 | 状态 |
|--------|--------|------|---------|------|
| C01 | 功能A | 具体描述 | 如何验证 | ⬜ |

| C03 | 接口C | 输入输出 | 如何验证 | ⬜ |

### 4. 自检报告（执行后填写）
- [ ] C01 是否通过？证据：
- [ ] C02 是否通过？证据：
- [ ] C03 是否通过？证据：
- 未通过项及原因：

### 5. 验收结论
| 检查人 | 日期 | 结论 | 备注 |
|--------|------|------|------|
|        |      | 通过/驳回 |      |
```

## Git Hook 检查

```bash
# .githooks/pre-commit
#!/bin/bash

# 检查是否有验收单关联
if ! grep -q "验收单:" "$COMMIT_MSG_FILE"; then
    echo "❌ 提交信息必须关联验收单"
    echo "格式: [验收单: #123] 提交说明"
    exit 1
fi

# 检查自检报告是否存在
TASK_ID=$(grep -oP '(?<=验收单: #)\d+' "$COMMIT_MSG_FILE")
if [ ! -f "checklist/TASK-$TASK_ID.md" ]; then
    echo "❌ 未找到验收单 checklist/TASK-$TASK_ID.md"
    exit 1
fi

echo "✅ 检查清单验证通过"
```
