## 1. 知识库电路（双闭环驱动）

```
闭环1：业务经验积累
├── 报价单 → 赢单/丢单 → 复盘 → 经验提炼 → 入库
├── 合同审核 → 风险发现 → 规则更新 → 知识库
└── 标书投标 → 中标/落标 → 经验总结 → 案例库

闭环2：AI能力提升
├── 知识库数据 → 训练/微调 → AI模型优化
├── 用户反馈 → 模型调优 → 知识库更新
└── 新数据录入 → 知识增强 → 业务提效
```

## 2. 知识库架构

```
知识库
├── 案例库
│   ├── 成功案例
│   │   ├── 行业分类
│   │   ├── 产品分类
│   │   └── 难度分级
│   └── 失败案例
│       ├── 原因分析
│       └── 教训总结
│
├── 技术文档库
│   ├── 产品说明书
│   ├── 技术白皮书
│   ├── API文档
│   └── 部署手册
│
└── 商务资质库
    ├── 企业资质证书
    ├── 人员资质证书
    ├── 业绩证明材料
    └── 合作伙伴资料
```

## 3. 案例库管理

### 3.1 案例分类

| 分类维度 | 选项 |
|---------|------|
| 行业 | 金融/政府/医疗/教育/企业 |
| 产品 | 安全/云/大数据/AI |
| 难度 | 简单/中等/复杂 |
| 结果 | 成功/失败 |

## 4. 技术文档库管理

### 4.1 文档分类

| 类型 | 说明 | 管理方 |
|------|------|--------|
| 产品说明书 | 产品功能、特性、规格 | 产品经理 |
| 技术白皮书 | 技术架构、实现原理 | 技术负责人 |
| API文档 | 接口定义、调用示例 | 开发团队 |
| 部署手册 | 部署步骤、配置参数 | 运维团队 |

### 4.2 文档版本管理

```
文档版本规则：
- 版本号：v{major}.{minor}.{patch}
- major：重大变更（架构调整）
- minor：功能更新
- patch：修正错误
```

## 5. 商务资质库管理

### 5.1 资质分类

| 类型 | 说明 | 有效期 |
|------|------|--------|
| 企业资质 | 营业执照、资质证书 | 长期/定期更新 |
| 人员资质 | 职称证书、执业证书 | 定期更新 |
| 业绩证明 | 合同、验收报告 | 长期 |
| 合作伙伴 | 合作协议、授权书 | 定期更新 |

### 5.2 资质到期提醒

```
资质到期提醒规则：
- 到期前90天：系统提醒
- 到期前30天：邮件+飞书提醒
- 到期前7天：紧急提醒
- 到期后：标记为过期，禁止用于投标
```
