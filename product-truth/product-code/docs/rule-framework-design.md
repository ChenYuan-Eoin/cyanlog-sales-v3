# 规则框架旧设计（已废弃）

本文件原正文是历史方案，不再是产品或实现依据。旧方案把 Level A/B/C、字段自动提取、单规则发布以及 `/api/rules` CRUD、`/api/rules/[id]/publish|test`、`/api/rules/simulate` 当成正式控制面；这些设计已经废弃，禁止据此新增或恢复实现。历史正文由 Git 历史保留。

当前唯一产品合同：

- [F009 合同规则配置](../../feature-packets/F009-contract-rule-config.md)
- 产品层级固定为：`规则集 → 问题分类 → 具体规则 → 规则详情 → 业务属性 → 判定与处理`。
- 规则集是唯一发布原子；草稿不会改变当前线上快照。
- 配置期不做“属性提取”、Prompt 或 AI 转译；AI 仅在运行期定位原文并读取事实，服务端按已发布的类型、运算符、阈值和处理动作确定性判定。
- canonical 控制面位于 `/api/contract-policies`；规则验收使用快照绑定的 `/api/rules/test`。其他旧 `/api/rules*` 控制面不得作为第二协议继续维护。

如代码、测试或其他文档与 F009 冲突，以 F009 和当前发布快照协议为准，并先消除冲突再继续开发。
