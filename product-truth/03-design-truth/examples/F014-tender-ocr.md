# F014 标书 OCR - 设计资产

## 视觉规范

### 信心度颜色

| 区间 | 颜色 | Token |
|------|------|-------|
| ≥ 80% | 高 | `emerald-100/700` |
| 50-80% | 中 | `blue-100/700` |
| < 50% | 低 | `slate-100/600` |

### 详情页结构

5 段统一卡片 + section 标题：
1. 基础信息（dl/dt/dd 双列网格）
2. 评分标准（表格：项目/权重/最高分）
3. 技术要求（项目列表）
4. 商务条款（行内文本）
5. 时间节点（表格：事件/日期）

### 空态

- 全部未识别时显示琥珀色提示
- 单字段未识别显示"未识别"灰色文字

## 与现有页面一致性

- 表格圆角/边框/hover 风格与 `/contracts/[id]` 保持一致
- 信心度 badge 与 F022 降级历史表格一致
- 列表页骨架沿用 F020/F021 的 `rounded-lg border` 模式
