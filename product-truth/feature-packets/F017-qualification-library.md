# Feature Packet: F017-商务资质库

**REQ ID**: F017  
**Status**: draft → design_in_progress  
**Priority**: P2  
**Upstream**: 知识库管理.md (已归档)

---

## 1. 目标

管理企业资质和人员资质，支持投标、合同签署。

## 2. 资质分类

| 类型 | 说明 | 有效期管理 |
|------|------|------------|
| 企业资质 | 营业执照、资质证书 | 长期/定期 |
| 人员资质 | 职称证书、执业证书 | 定期更新 |
| 业绩证明 | 合同、验收报告 | 长期 |
| 合作伙伴 | 合作协议、授权书 | 定期更新 |

## 3. 到期提醒

| 时间 | 方式 |
|------|------|
| 到期前90天 | 系统提醒 |
| 到期前30天 | 飞书+邮件 |
| 到期前7天 | 紧急提醒 |
| 到期后 | 标记过期，禁止投标 |

## 4. MVP 范围

- [ ] 资质 CRUD
- [ ] 到期提醒
- [ ] 投标时快速选择资质
