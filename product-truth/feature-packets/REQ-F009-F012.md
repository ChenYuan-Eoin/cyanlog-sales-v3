## 技术方案

### 数据模型

统一配置表 `configs`：

```sql
create table configs (
  id uuid primary key default gen_random_uuid(),
  key text not null unique,           -- 配置键，如 TAX_STANDARD
  name text not null,                 -- 显示名称
  value jsonb not null,               -- 配置值 JSON
  type config_type not null,          -- 配置类型枚举
  status config_status default 'draft', -- draft/published/archived
  version int default 1,              -- 版本号
  description text,
  org_id uuid references organizations(id),
  created_by uuid references auth.users(id),
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

-- 配置版本历史表
create table config_versions (
  id uuid primary key default gen_random_uuid(),
  config_id uuid references configs(id),
  version int not null,
  value jsonb not null,
  created_by uuid references auth.users(id),
  created_at timestamptz default now()
);
```

### API 设计

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/configs | 配置列表（按 type 筛选） |
| GET | /api/configs/:id | 配置详情 |
| POST | /api/configs | 创建配置 |
| PUT | /api/configs/:id | 更新配置 |
| DELETE | /api/configs/:id | 删除配置 |
| POST | /api/configs/:id/publish | 发布配置 |
| GET | /api/configs/:id/versions | 获取版本历史 |
| POST | /api/configs/:id/rollback | 回滚到指定版本 |

### 配置类型定义

#### 税率规则 (TAX_RULE)
```typescript
{
  code: string,          // 税率编码 TAX_XXX
  name: string,          // 显示名称
  rate: number,          // 税率 0.13
  category: string,      // 类别：货物销售/服务/运输
  region: string,        // 地区
  effective_date: string,
  enabled: boolean
}
```

#### 审批权限 (APPROVAL_RULE)
```typescript
{
  rule_type: 'discount' | 'contract',
  thresholds: Array<{
    limit: number,
    approver_role: string,
    enabled: boolean
  }>
}
```

#### AI 模型配置 (AI_CONFIG)
```typescript
{
  level: number,         // 1=本地, 2=云端, 3=规则
  name: string,
  base_url: string,
  api_key?: string,
  model: string,
  timeout_ms: number,
  enabled: boolean,
  routing?: {
    max_pages: number,
    strategy: 'full' | 'chunked'
  }
}
```
