# F052 引导式报价向导

- 状态: in_progress
- 优先级: P1
- 来源: 用户要求（报价形态）+ CPQ 市面形态（guided selling）

## 形态
new-ones 从单页表单改为**三步引导向导**：
1. 选品与配置：客户/联系人/有效期/区域 + 产品 → 版本 → 部署 → 授权 → 期限（逐级联动）
2. 数量与折扣：数量/行折扣档位/赠送 + 整单折扣档位/原因
3. 确认提交：算价汇总（小计/折扣/税/大写）+ 自动审核核验提示 + 保存

- 步骤条导航 + 上一步可回改 + 每步校验（Step1 行完整、Step2 折扣原因必填）
- 预览实时算价（数量修改后 Step3 合计实时刷新 <500ms）
