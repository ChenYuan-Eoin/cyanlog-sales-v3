## 1. 单元定义

**目标**：建立结构化报价工作台，销售在这里录入业务事实，系统读取配置中心已发布配置后完成自动算价、折扣判断、审批触发和报价快照固化。

**这包拥有的内容**：
- 报价头与报价明细
- 数量、单价、税率、折扣后的金额快照
- 报价状态流转
- 报价详情与导出入口

**这包不拥有的内容**：
- SKU 价格维护
- 税率规则维护
- 折扣矩阵维护
- 审批权限维护

这些都属于配置中心。

---

## 2. 配置消费边界

| 配置来源 | F002 读取什么 | F002 不允许做什么 |
|----------|---------------|-------------------|
| `F001` | SKU、基础价、阶梯价 | 改 SKU 价格 |
| `F010` | 税率、折扣矩阵、审批流参数 | 改规则阈值 |
| `F011` | 当前用户审批权限、数据范围 | 改角色或数据范围 |

F002 的职责是”记录业务输入并固化结果”，不是”在业务页改配置”。

---

## 3. 报价工作台定位

**报价工作台是独立完成报价流程的工作面，不是 CRM 的取数末端**。

| 维度 | 报价工作台 | CRM 关系 |
|------|-----------|---------|
| **核心职责** | 报价单全生命周期管理 | 客户数据来源/同步方 |
| **操作主体** | 销售在报价中心操作 | CRM 系统维护客户主数据 |
| **数据流向** | 从 CRM 拉取客户信息 | 接收报价结果回写 |
| **Source of Truth** | 报价中心数据库 | CRM 客户主数据库 |

**独立开局能力**：
- 支持快速录入客户（仅名称+电话），后续补全
- CRM 离线时仍可创建报价（标记”待同步”）

## 5. 产品电路

### 5.1 输入层
```
├── 客户信息（双路径）:
│   ├── CRM 同步：自动填充历史联系人/成交价
│   └── 快速路径：仅填客户名称+电话
├── 产品信息（F001 价盘）:
│   ├── 基础价：SKU 标准价
│   └── 阶梯价：按数量命中区间单价
└── 折扣触发检测:
    ├── IF 折扣率 ≤ 个人权限 → 免审通过
    ├── IF 折扣率 > 权限且 ≤ 经理权限 → 触发审批
    └── IF 折扣率 > 经理权限 → 触发总监审批
```

### 5.2 处理层（实时计算）
```
行级：quantity × unitPrice - lineDiscount = lineTotal
小计：Σ lineTotal = subtotal
税费：subtotal × taxRate = taxAmount
总计：discountedAmount + taxAmount = totalAmount
```

### 5.3 输出层
- PDF 导出
- 飞书卡片通知
- 下游触发：SENT → 创建跟进提醒；CONFIRMED → 触发合同草稿
- 版本固化：每次”发送”生成 immutable 版本

报价创建流程至少包括：
1. 选择客户
2. 选择 SKU 与数量
3. 命中阶梯价并计算行金额
4. 命中税率并计算税额
5. 应用折扣并检查是否超权限
6. 需要时触发审批
7. 固化报价快照

## 4. 状态机

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| `DRAFT` | 草稿 | 编辑、提交审批 |
| `PENDING_APPROVAL` | 审批中 | 查看、催办 |
| `APPROVED` | 已批准 | 查看、发送、导出 |
| `REJECTED` | 已驳回 | 修改后重新提交 |
| `SENT` | 已发送 | 查看、跟踪、客户确认 |
| `CONFIRMED` | 已确认 | 生成合同草稿 |
| `VOID` | 已作废 | 查看 |

**完整生命周期**：
```
新建 → 草稿 → [提交] → 审批中 → [通过] → 已批准 → [发送] → 已发送 → [确认] → 已确认 → [生成] → 合同
          ↓           ↓拒绝         ↓           ↓拒绝
        作废        草稿(重编)     草稿(重编)   已拒绝 → [新建版本v2]
```

---

## 5. 快照原则

报价保存的是“命中结果”，不是“配置引用”：
- 行单价保存命中的 SKU 价格
- 税率保存命中的规则结果
- 折扣保存当时的审批判断

否则配置中心后续改价、改税、改权限，会污染历史报价。
